# 통제실 지도 (4-3)

`/admin/factory?tab=map` — 메인 PC·서버1·서버2와 그 안의 블록이 어떻게 이어졌는지 선으로 보는 **보기 전용** 화면.

## 블록과 선

| 열 | 블록 | 자료 |
|---|---|---|
| 기계 | 메인 PC(감독 버전·연결·슬롯), 서버1, 서버2 | 감독 상태, 장비 보고(docker ps) |
| 에이전트 | A1~A4·R1·L1·T·C1·M1·H1 | 에이전트 정의(4-2) + 권한 상한 |
| 도구 | 도구 설명서(2-1) | 툴킷 보고 |
| 카드 | 결과물 카드(2-2) | factory_cards |
| 앱 폴더 / git 원격 | 연결 표(1-6)의 폴더·브랜치·배포 원격 | 감독 보고 + 연결 표 |
| 서버 안 | 프록시 → 도메인 → 컨테이너 | 연결 표(사람이 적은 값) + docker ps |

선: 앱 폴더 → 배포 git 원격 → 컨테이너(원격 기록이 없으면 점선), 에이전트 → 쓰는 도구(A1~A4 = 도구 요청 중계, T = 카드가 쓰는 도구), 카드 → 도구, 카드 → 앱, 프록시 → 도메인 → 컨테이너.
**nginx 설정은 읽지 않는다.** 프록시·도메인 선은 연결 표에 기록된 범위만이고, 서버2 도메인은 프록시 연결 기록이 없다고 표시한다.

## 상태 색 (색 + 모양 + 글자)

● 정상 · ◆ 작업 중 · ◔ 배포 대기(정비 코드 배포 대기·승인/검토 대기) · ✕ 끊김·못 찾음 · ▲ 경고(원격 없음, 설명서 fallback, 오래된 보고 등).
컨테이너 목록을 못 받은 서버는 "못 찾음"이 아니라 "상태 미확인(경고)"으로 둔다.

## 블록을 누르면

- **에이전트**: 실제 적용 권한 = 정의 + 코드 상한(`CEILING`) + 훅. 허용 도구, 막은 도구, 쓸 수 있는 경로, 쓰기·읽기 금지, 네트워크, SSH 대상, 받는 키 이름(값 없음), 훅, 넘기는 환경변수 이름. 계산은 `tools/factory-supervisor/agentspec.mjs` 의 `effectivePermissions`. 상한을 넓힌 정의는 불러올 때 거절되어 지도에서 빠지고 메인 PC 상세에 이유가 나온다.
- **서비스(컨테이너)**: 상태, 도메인, 연결된 프로젝트. **앱**: 원격, 브랜치, 최근 일감. **기계**: 버전·연결·슬롯·장비 보고.
- 진행 중 일감은 에이전트·앱·메인 PC 블록에 `▶ 제목 · 단계` 한 줄로 뜬다(5초마다 새로 받음).
