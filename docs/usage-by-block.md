# 블록별 비용·시간 통계 (4-4)

[사용량] 탭의 AI 사용량 계기판은 그대로 두고, 그 아래에 **블록 단위 집계**를 더했다. 보기 전용이고, 키·토큰 값은 어디에도 없다.

## 무엇을 기록하나

일감·정비 지시·지휘자 판단이 **끝나는 순간** 표 `factory_run_stats` 에 한 줄을 남긴다(`lib/factory/runStatsDb.ts`). 이미 있는 값은 그대로 가져오고, 없던 값(토큰·중지 시간·결과 분류)만 채운다.

| 값 | 어디서 | 비고 |
| --- | --- | --- |
| 토큰 | Claude 사용량 이벤트(`claude_events`) | 사용량 이벤트는 14일 뒤 지워져서 끝날 때 한 줄로 옮겨 둔다 |
| 대기 | 승인(없으면 등록) → 시작 | 정비는 등록 → 시작 |
| 실행 | 시작 → 끝, 일시 중지 뺀 값 | |
| 일시 중지 | 서버 배포(`factory_deploys`) 구간과 겹친 시간 | 배포 중에는 홈페이지가 응답하지 않아 보고가 멈춘다. 감독 프로그램 업데이트 일시 중지는 시각이 따로 기록되지 않아 아직 못 센다 |
| 결과 | 성공 / 실패 / 막힘 | 막힘 = 키 부족·합치기 실패·비용 한도 확인 대기 (`classifyResult`) |
| 다시 맞추기 | 병행 상태의 `rebases` | 병행 일감만 0 이상 |
| 외부 비용 | 도구 일감 결과의 `cost` | PixelLab 호출 수. 단위 글자도 같이 저장 |

기록하는 자리: `reportJob`(done·failed·review·linkwait·needs_confirmation), 정비 `reportTurn`, 지휘자 `appendLog`. 모두 **실패해도 던지지 않는다**(통계 한 줄만 빠짐). 같은 일감·같은 시도 번호는 덮어쓴다.

### 알려진 한계
- 일감별 Claude 세션을 서버가 모른다. 일감 토큰은 `같은 앱 + 시작~끝 시간 + 같은 감독 PC` 의 사용량 이벤트 합이고, 같은 앱에서 겹쳐 돈 다른 일감 수만큼 **나눠** 센다(대략값). 정비는 세션 id 로 정확히 센다.
- Codex 일감·정비는 토큰이 0 이다(사용량 이벤트가 Claude 만 있음). 도구 일감도 AI 를 안 써서 0.
- 임대 만료로 서버가 직접 실패 처리한 일감은 보고가 없어 줄이 없다.
- 이 기능이 들어가기 전에 끝난 일은 기록이 없다.

## 집계 단위 (`lib/factory/runStats.ts`)
- 에이전트 종류(4-2 번호: A1 A2 A3 R1 L1 T M1 C1) · 앱 · 결과물 카드 · 도구·방법
- 기간: 일(최근 24시간) · 주(최근 7일) · 월(최근 30일). 표와 같이 흐름 막대(일=7일 일별, 주=8주, 월=30일 단위 6칸)도 나온다
- 토큰 합계 = 입력 + 출력 + 캐시 생성 (캐시 읽기는 합계에서 빼고 상세에만 둠)

## 화면
- [사용량] 탭 아래 "블록별": 묶음 기준·기간 단추, 표(횟수·결과·토큰·대기·실행·중지·다시 맞추기·외부 비용·합계), 토큰 막대, 기간 흐름 막대 — `components/admin/factory/BlockUsagePanel.tsx`
- 통제실 [지도](4-3)와 스튜디오 [구성](3-1) 블록에 **최근 7일 요약 한 줄**(`7일 3회 · 12K 토큰 · 25분 · 실패·막힘 1`). 에이전트·도구·카드·앱(프로젝트) 블록만. 기록이 없으면 `7일 기록 없음`. 칸 높이를 조금 키웠다(`MAP_H` 110, `NODE_H` 106)

## API·커넥터
